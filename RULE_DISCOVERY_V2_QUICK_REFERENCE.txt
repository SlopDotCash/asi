================================================================================
INTEGRATION WITH EXISTING RULE DISCOVERY
================================================================================

The templates are designed to integrate seamlessly with the existing
rule_discovery module (alberta_framework/benchmarks/rule_discovery.py).

No changes required to existing code. To use templates:

Option 1: Inject into default seed population (manual)
  from rule_discovery_v2_integration import expand_seed_genomes_with_templates
  extended_seeds = expand_seed_genomes_with_templates()
  # Pass extended_seeds to search initialization

Option 2: Register templates in rule_discovery.seed_genomes() (optional)
  - Modify seed_genomes() to include templates automatically
  - All future search runs will include them
  - One-line change in rule_discovery.py

Option 3: Create separate search run with template-specific config
  - Use CLI with templates injected via Python import
  - No modification to existing rule_discovery.py needed

Recommended: Option 1 (manual injection) for Phase 2 to track template origin
