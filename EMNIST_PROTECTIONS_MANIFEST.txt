================================================================================
THE FOUR PROTECTION MECHANISMS
================================================================================

1. FEATURE-WISE NORMALIZATION
   Purpose: Prevent feature distribution drift and maintain numerical stability
   Implementation: Per-feature running statistics with momentum-based EMA
   State: FeatureWiseNormState (mean, var, min, max, counters)

2. CATASTROPHIC FORGETTING DETECTOR
   Purpose: Detect and respond to accuracy collapses during task transitions
   Implementation: Monitors accuracy drops, triggers recovery mode on detection
   State: ForgettingDetectorState (history, threshold, recovery counter)

3. PER-CLASS BATCH NORMALIZATION
   Purpose: Handle class imbalance and class-specific feature distributions
   Implementation: Maintains separate statistics for each of 47 EMNIST classes
   State: PerClassBatchNormState (class means, vars, counts, last-seen)

4. TASK-AWARE DROPOUT SCHEDULING
   Purpose: Promote exploration after task switches, decay to exploitation
   Implementation: Adaptive dropout with exponential/linear/cosine decay
   State: TaskAwareDropoutState (base rate, stability, usage, schedule)

DESIGN PRINCIPLES
================================================================================

1. Orthogonal Mechanisms - Each protection is independent
2. Explicit State - All state in frozen dataclasses
3. Temporal Uniformity - Updates every step (no train/eval separation)
4. Numerical Stability - Epsilon handling and overflow protection
5. JAX-Native - Pure JAX operations, JIT-compatible
6. Configuration-Friendly - All hyperparameters exposed
